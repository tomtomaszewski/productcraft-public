# Product Craft

Publiczne materiały, które przygotowuję w ramach [Product Craft](https://productcraft.pl/).

To prompty i ćwiczenia, których sam używam w pracy produktowej. Możesz je skopiować i uruchomić u siebie.

## Co jest w repo

- [LNO](LNO/) - audyt zadań i użycia AI przez pryzmat Leverage, Neutral i Overhead. Skill do instalacji: [lno-framework](LNO/lno-framework/).

Żeby zainstalować skill LNO w Cursorze, skopiuj folder do swoich skilli:

```bash
cp -R LNO/lno-framework ~/.cursor/skills/
```
- [product-diagnosis-frameworks](product-diagnosis-frameworks/) - prompty do diagnozy sytuacji produktowej. Każdy odpowiada na jedno pytanie (funnel, trend, root cause, leading vs lagging, hypothesis, tradeoff) i kończy się efektem, z którego da się zdecydować, co sprawdzić dalej.
